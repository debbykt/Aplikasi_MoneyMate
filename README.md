MoneyMate : 
Aplikasi Pencatatan Keuangan

Deskripsi :
MoneyMate adalah aplikasi pencatatan keuangan pribadi berbasis web yang membantu pengguna mencatat pemasukan dan pengeluaran serta memantau kondisi keuangan dengan lebih mudah.

Fitur utama :
Dashboard untuk menampilkan total saldo, total pemasukan, dan total pengeluaran.
Daftar Transaksi untuk menampilkan catatan transaksi beserta kategori, tanggal, jenis, dan nominal.
Tambah Transaksi untuk memungkinkan pengguna menambahkan transaksi baru melalui formulir.
Perhitungan Otomatis untuk memperbarui ringkasan keuangan berdasarkan transaksi yang tercatat.
Responsive Design dirancang agar tampilan menyesuaikan ukuran layar desktop maupun mobile.

Teknologi yang digunakan :
React
Vite
Bootstrap
CSS
JavaScript

Cara menjalankan aplikasi :

Pastikan Node.js sudah terpasang.
Buka terminal pada folder proyek.
Jalankan perintah berikut untuk memasang dependensi 

   ```bash
   npm install
   ```

Jalankan aplikasi

   ```bash
   npm run dev
   ```

Buka alamat lokal yang muncul di terminal pada browser.

Data transaksi pada versi ini disimpan sementara selama aplikasi berjalan. Data belum tersimpan secara permanen ke database atau penyimpanan lokal.

MoneyMate dibuat sebagai proyek pembelajaran pengembangan aplikasi web menggunakan React dan Vite.
